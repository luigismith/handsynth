# HandSynth

A gestural synthesizer played with your hands and a webcam. Move, pinch, open and close — and a Tone.js audio engine plus a generative music brain respond in under 20 ms. Four built-in vibes (Tycho, Bonobo, Hopkins, Floating Points) set tonality, tempo, and timbre.

## Run it

```sh
pnpm install
pnpm dev
```

Then open the printed URL (typically `http://localhost:5173`). Click **permetti webcam** when prompted.

## Build

```sh
pnpm build      # static output in dist/
pnpm preview    # preview the production build locally
```

## Quality

```sh
pnpm typecheck
pnpm lint
pnpm test
```
