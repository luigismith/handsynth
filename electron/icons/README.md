# HandSynth — App Icons

This folder holds the platform icons used by `electron-builder` when packaging
HandSynth into an installer.

## What's here

- **`icon.png`** (512×512, RGBA) — placeholder icon: orange "H" on charcoal.
  Generated by `generate-placeholder.cjs` using only Node's built-in `zlib`
  (no `sharp`/`canvas` dep required). This file is committed so a clean clone
  builds out of the box. Replace it with the real branded icon when ready.
- **`generate-placeholder.cjs`** — the generator script. Re-run with
  `node electron/icons/generate-placeholder.cjs` if you want to tweak the
  colours/glyph and regenerate.
- **`icon.ico`** *(not committed)* — required by `electron-builder` for proper
  Windows installer + taskbar icons. Generate from `icon.png`.
- **`icon.icns`** *(not committed)* — required for proper macOS app/dock icons.
  Generate from `icon.png`.

## Required formats per platform

| Platform | File       | Format                                         |
|----------|------------|------------------------------------------------|
| Windows  | `icon.ico` | Multi-resolution `.ico` (16, 32, 48, 64, 128, 256) |
| macOS    | `icon.icns`| Standard Mac iconset (16→1024 with @2x)        |
| Linux    | `icon.png` | 512×512 PNG (already present)                  |

`electron-builder` does **not** auto-convert PNG → ICO/ICNS. The build will
still complete with only the PNG, but the installer and the resulting app
will fall back to the default Electron icon for some surfaces.

## Generating the platform-specific files

### Windows `.ico`

```sh
# requires Node ≥ 16
npx png-to-ico electron/icons/icon.png > electron/icons/icon.ico
```

Or with ImageMagick:

```sh
magick convert electron/icons/icon.png \
  -define icon:auto-resize=256,128,64,48,32,16 \
  electron/icons/icon.ico
```

### macOS `.icns`

On macOS:

```sh
mkdir -p icon.iconset
sips -z 16 16     electron/icons/icon.png --out icon.iconset/icon_16x16.png
sips -z 32 32     electron/icons/icon.png --out icon.iconset/icon_16x16@2x.png
sips -z 32 32     electron/icons/icon.png --out icon.iconset/icon_32x32.png
sips -z 64 64     electron/icons/icon.png --out icon.iconset/icon_32x32@2x.png
sips -z 128 128   electron/icons/icon.png --out icon.iconset/icon_128x128.png
sips -z 256 256   electron/icons/icon.png --out icon.iconset/icon_128x128@2x.png
sips -z 256 256   electron/icons/icon.png --out icon.iconset/icon_256x256.png
sips -z 512 512   electron/icons/icon.png --out icon.iconset/icon_256x256@2x.png
sips -z 512 512   electron/icons/icon.png --out icon.iconset/icon_512x512.png
cp electron/icons/icon.png             icon.iconset/icon_512x512@2x.png
iconutil -c icns icon.iconset -o electron/icons/icon.icns
rm -rf icon.iconset
```

Cross-platform alternative: `npx electron-icon-builder --input=electron/icons/icon.png --output=electron/icons --flatten`.
